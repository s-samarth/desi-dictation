# Planned Features (private)

Each planned feature gets one doc following the same structure:

1. **Explainer** — what the feature is, in one screen
2. **The user** — who it's for, what problem it solves (see [PERSONAS.md](PERSONAS.md))
3. **User flow** — step by step, from the user's seat
4. **Technical plan** — how it fits the existing system
5. **Rollout & feedback** — how we ship and learn under the no-telemetry promise
6. **What makes it good** — the success criteria we'd judge it by
