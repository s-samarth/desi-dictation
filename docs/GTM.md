# Go-To-Market — Desi Dictation

Solo-dev GTM: zero ad budget, distribution through authenticity and demos.
Pre-launch checklist lives in [LAUNCH.md](LAUNCH.md); this is the strategy.

## The one asset that matters

A **10-second screen recording**: WhatsApp Web open, hold Right ⌥, say
*"bhai kal ka plan cancel karna padega, client meeting aa gayi hai"*, release —
perfect Roman Hinglish appears. That GIF **is** the pitch: no landing page copy
will outperform it. Make 5–6 variants (Slack, VS Code + Claude, Gmail, Notes).

## Phases

### Phase 1 — Quiet beta (weeks 1–3)
- 20–30 hand-picked Indian devs on Macs (DMs, r/developersIndia, Twitter circle).
- Free Pro keys for feedback + eval-clip contributions (grows the Hinglish
  test set — a compounding asset).
- Goal: kill insertion bugs across their app mix; collect 3 testimonials.

### Phase 2 — Public launch (week 4)
Sequence (each links the Gumroad page):
1. **Twitter/X thread** — build-in-public story: "MacWhisper is great but it
   can't hear my Hinglish, so I built this" + the GIF. Personal story > feature list.
2. **Product Hunt** — "Dictation app for Hinglish speakers"; India-morning launch.
3. **r/developersIndia + r/india** — dev-story framing, not ad framing.
4. **Hacker News Show HN** — lead with the local-first/whisper.cpp engineering
   angle; HN loves on-device ML and hates subscriptions.
5. **LinkedIn** — the "I built a product for India" arc travels far there.

### Phase 3 — Content engine (ongoing)
- Reels/Shorts of real dictation moments (@samcatchesup synergy — AI/tech
  content for reach is literally the account's beat).
- SEO posts: "hinglish dictation mac", "speech to text hindi english mixed",
  "MacWhisper alternative India".
- Comparison page: honest "Desi Dictation vs MacWhisper" (link MacWhisper
  generously — confidence reads as credibility).

## Objection handling (bake into page copy)

- *"Whisper is free, why pay?"* → You're paying for the tuned Hinglish models
  wired into a polished hold-a-key workflow, not for Whisper.
- *"Is my voice uploaded?"* → Never. Audio is processed on your Mac. (Headline it.)
- *"Will it work on my M1 Air 8GB?"* → Yes — free model runs in ~350 MB RAM;
  Pro model has a q5 build for 8 GB machines.
- *"MacWhisper exists"* → We love it. It doesn't speak Hinglish. (Comparison page.)

## What NOT to do

- No "AI note taker" positioning — crowded, undifferentiated.
- No meeting-bot features pre-PMF — the wedge is dictation.
- No subscription. It's a differentiator, keep it sacred.
- No English-market launch messaging — the niche IS the strategy.
